# PingMD 🏥

A modern, intuitive web application for booking doctor appointments with ease. Connect with healthcare professionals and schedule your consultations seamlessly.

**Live Demo:** [https://ping-md.vercel.app](https://ping-md.vercel.app)

---

## 🌟 Features

- **Easy Appointment Booking** - Browse available doctors and book appointments in just a few clicks
- **Doctor Profiles** - View detailed profiles, specializations, and availability of healthcare professionals
- **Real-time Scheduling** - Check doctor availability in real-time and pick convenient time slots
- **User-friendly Interface** - Intuitive and responsive design for seamless user experience
- **Secure & Reliable** - Built with modern security practices to protect user data

---

## 🛠️ Tech Stack

- **Frontend Framework:** Next.js with TypeScript (68.7%) & JavaScript (27.1%)
- **Styling:** CSS (4.2%)
- **Deployment:** Vercel
- **Language:** Primarily TypeScript for type-safe development

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Radhikaa-chauhan/PingMD.git
   cd PingMD
   ```

2. **Navigate to frontend directory**
   ```bash
   cd frontend
   ```

3. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

5. **Open in browser**
   ```
   http://localhost:3000
   ```
